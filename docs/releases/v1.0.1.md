
MioProxy v1.0.1 is the first maintenance release in the 1.0 series, focusing on **more accurate and reliable proxy latency testing** and improved release reproducibility.

## ✨ What's Changed

### Latency Testing

- Fixed missing proxy-group context during latency tests.
- Proxy groups now correctly use their configured test URL when available.
- Fixed incorrect latency reuse when nodes with the same name appear in different proxy groups.
- Latency cache entries are now isolated by proxy group, node, provider, test URL, and related context.
- Improved distinction between ordinary proxies, proxy groups, built-in entries, and real Mihomo proxy providers.
- Correctly handles Mihomo `Compatible` providers so internal aggregation providers are not mistaken for subscription providers.
- Latency values are displayed directly from Mihomo Controller responses without artificial normalization or adjustment.

### Stability & Release

- Improved Mihomo provider resolution and latency request routing.
- GeoSite / GeoIP are now maintained as repository-pinned snapshots and verified with SHA-256, preventing mutable upstream `latest` updates from breaking reproducible builds.
- Added a dedicated geodata maintenance workflow for intentional GeoSite / GeoIP updates.
- Strengthened Release, Updater, and supply-chain integrity checks.

## 📥 Download

Windows x64 users should download:

**`MioProxy_1.0.1_x64-setup.exe`**

Install it and start using MioProxy.

> MioProxy currently does not use Windows Authenticode code signing, so Windows may display an **Unknown Publisher** warning. This does not affect the cryptographic signature verification used by MioProxy's built-in Tauri updater.
