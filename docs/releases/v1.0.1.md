# MioProxy v1.0.1

MioProxy v1.0.1 是首个 1.0 系列维护更新，重点改善 **代理节点延迟测试的准确性与稳定性**，并增强发布流程的可复现性。

## ✨ 本次更新

### 延迟测试

- 修复节点测速缺失代理组上下文的问题。
- 代理组配置了测试 URL 时，现在会正确使用该 URL。
- 修复同名节点位于不同代理组时可能复用错误延迟结果的问题。
- 延迟缓存现在按代理组、节点、Provider、测试 URL 等上下文隔离。
- 正确区分 Mihomo 的普通代理、代理组、内置节点与真实 Proxy Provider。
- 正确识别 Mihomo `Compatible` Provider，避免将内部聚合 Provider 错认为订阅 Provider。
- 延迟结果直接使用 Mihomo Controller 返回值，不做人为修正或美化。

### 稳定性与发布

- 改进 Mihomo Provider 解析和延迟请求路径。
- GeoSite / GeoIP 改为仓库固定快照，并通过 SHA-256 验证，避免上游 `latest` 更新导致旧版本无法复现构建。
- 增加独立的 geodata 更新维护流程。
- 加强 Release、Updater 和供应链完整性验证。

## 📥 下载

Windows x64 用户请下载：

**`MioProxy_1.0.1_x64-setup.exe`**

安装后即可使用。

> MioProxy 当前未使用 Windows Authenticode 代码签名，因此 Windows 可能显示“未知发布者”提示。这不影响 MioProxy 内置的 Tauri updater 签名验证。
